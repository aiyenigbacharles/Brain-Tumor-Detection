# brain-tumour-detection-app


This is a Deep Learning application that uses a Convolutional Neural Network (CNN) to detect brain tumors from MRI images.

Overview This application uses a PyTorch-based CNN model to analyze brain MRI scans and determine whether a tumor is present. The web interface is built with Streamlit, providing an easy-to-use tool for medical professionals or researchers.

Features Upload brain MRI images in JPG or PNG format Real-time prediction of tumor presence Simple and intuitive user interface Pre-trained neural network model
